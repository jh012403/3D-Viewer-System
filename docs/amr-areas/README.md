# AMR 주행 후보·이격 제외 영역

상자 마무리 커밋 `5110ea0` 이후 사용자가 선택한 첫 단계입니다. 경로 생성, 로봇 제어 또는 실측 안전 인증 기능은 포함하지 않습니다.

현장 상단의 **AMR 영역**을 켜면 녹색 주행 후보와 빨간 자산 이격 제외 영역을 표시합니다. 기본값은 꺼짐이며, 이격 거리는 기본 0.5m에서 조절할 수 있습니다. 반입 미리보기·확정·이동·삭제를 반영합니다.

- 피팅한 중력축의 바닥 평면에 6cm 격자를 구성합니다.
- 바닥 자산의 사진 영역 안에서 실제 깊이 샘플과 평면의 차이가 4cm 이하인 위치만 표시합니다. 전체 셀이 바닥 영역 안에 있어야 하며, 확인하지 않은 공간은 비워 둡니다.
- 기존 자산과 반입 메시의 3D AABB 모서리를 바닥에 투영한 볼록 다각형으로부터 이격 거리를 계산합니다. 높이별 통과 가능성은 고려하지 않는 보수적인 투영입니다.
- 배경 깊이 가림과 기존 배치 렌더링을 사용합니다. 오버레이는 바닥에 정렬되어 회전 시 함께 움직입니다.
- 주행 후보는 로봇 중심이나 차체 크기가 확정된 안전 영역이 아닙니다. 아직 로봇 폭·회전 반경·경사 허용치·연결성·동적 사람 추적을 계산하지 않습니다. 따라서 UI도 **주행 후보**, **시뮬레이션**, **사진 기반 추정**으로 표시합니다.
- 바닥을 확인하지 못한 장면에서는 토글을 비활성화합니다. 장면을 바꾸면 오버레이가 꺼지고 이전 상태를 폐기합니다.

## 실행 검증

`frontend/scripts/check-amr-areas.mjs` 결과는 `checks.json`입니다. 실제 브라우저에서 기존 job_000003을 가져와 검증했습니다.

| 상황 | 주행 후보 셀 | 이격 제외 셀 |
|---|---:|---:|
| 반입 전, 0.5m | 60 | 201 |
| 반입 미리보기·확정, 0.5m | 23 | 238 |
| 반입 자산 삭제 후, 0.5m | 60 | 201 |

이격 거리 0.8m에서 제외 영역 증가, 0m에서 감소, 토글 숨김 및 바닥 없는 도자기 장면 전환을 검증했습니다. 브라우저 오류 0건입니다. 이는 기능 회귀 검증이며 인식 정확도 평가가 아닙니다.
