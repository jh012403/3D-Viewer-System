# 반입 상자 접지 수정

장면은 `twin-logistics`로 통일합니다. 기존 시연 캐시·메시·발표 이미지는 변경하지 않습니다.

## 1차: 중력축과 카메라

- EQ-0001 바닥의 2D 영역 안에 투영되는 깊이 점 5,075개를 사용했습니다. 반복 절삭 직교 최소제곱 피팅으로 4,157개를 유지했습니다.
- 법선은 `[-0.013542, 0.656948, 0.753814]`, 화면 Y축과의 차이는 48.93°입니다. 평면 잔차 RMS는 0.00728m입니다. 이는 추정 깊이에 대한 피팅 잔차이며 실측 정확도가 아닙니다.
- 물체 up, 지지면 투영, 높이 조절, 이동 탐색, 스냅 및 로컬 기즈모가 이 법선을 사용합니다. 카메라 자체를 중력축으로 회전시키지 않습니다.
- 카메라는 캐시에 기록된 SHARP 입력 K의 fx/fy/cx/cy로 비대칭 투영행렬을 구성합니다. 기존 프리뷰 줌을 제거했습니다. 현재 장면의 원본 시점 투영행렬은 수정 전과 수치 오차 범위에서 같습니다. SHARP 입력 초점거리는 EXIF/기본 추정이며 실측 캘리브레이션은 아닙니다.
- 하위 2% 정점 높이를 기준으로 0.015m 묻습니다. `axis.json`에 실제 브라우저의 법선·쿼터니언·접지 수치를 기록했습니다.
- `before-*.png`: 기존 job_000002, 수정 전. `axis-*.png`: 같은 메시와 추천 위치에서 축·접지 수정 후. 원본/−5°/+5° 각각 보존합니다. 이 중간 화면은 새 메시 교체 전이며, 0.50m 이격 기준에서 랙까지 0.457m여서 확정하지 않은 미리보기입니다.

원본 사진을 SAM3로 분리해 TRELLIS.2-4B에 입력합니다. 저작자·라이선스 원본 응답은 `photo-provenance.json`입니다. job_000003의 웹 요청은 마스크 생성 후 대기 시간 초과가 발생해, 저장된 실제 마스크 `sam3_text_0000`을 API로 선택하여 생성 작업을 이어갔습니다.

## 2차: 실제 메시 교체

`job_000003`은 TRELLIS.2-4B 1024 cascade로 실제 생성됐습니다(531.771초, seed 363987120). `mesh-input.png`는 실제 분리 입력, `mesh-result.png`는 기존 단독 메시 뷰어입니다. 단독 GLB 다운로드 16,140,568바이트 및 브라우저 오류 0건을 확인했습니다.

UV 이음매를 합친 검사 사본에서 하단 열린 경계 63개를 발견해, 두께 4.5mm의 닫힌 바닥 캡(204개 정점, 404개 면)을 추가했습니다. 캡 자체는 watertight입니다. 전체 메시의 나머지 작은 열린 경계까지 복구했다고 주장하지 않습니다. 원본 `object_mesh.glb`는 보존하고, 씬 가져오기는 `object_mesh_grounded.glb`를 사용합니다. 긴 변을 통로 방향으로 놓도록 이 자산에만 90° yaw 프로필을 지정했습니다.

재현 명령(저장소 루트):

```powershell
.runtime/scene312-env/Scripts/python.exe scripts/check_box_bottom.py storage/outputs/job_000003/object_mesh.glb storage/outputs/job_000003/object_mesh_grounded.glb --report docs/placement-correction/mesh-bottom.json --yaw 90
```

생성 원본·보정 GLB·가중치는 기존 정책대로 로컬 ignored 자산이며, 원본/보정본 SHA-256과 캡 정보는 `mesh-bottom.json`, 실제 추론 기록은 `trellis-run.json`에 남겼습니다. 기존 사진 업로드·물체 선택·독립 GLB 다운로드 경로는 유지됩니다.

## 최종: 그림자·톤·표시 및 비교

[비교 갤러리](index.html)에서 원본·−5°·+5°의 수정 전후를 볼 수 있습니다. `comparison-*.png`는 1920×1080이며, 각 패널 아래 한글 라벨이 있습니다. 전체 UI 캡처는 `after-*.png`, 실제 런타임 수치는 `after.json`입니다.

| 항목 | 수정 전 | 수정 후 |
|---|---|---|
| up | 화면 Y축 | EQ-0001 깊이 점에서 피팅한 법선 |
| 카메라 | 프리뷰 줌, 중앙 주점 가정 | 캐시의 SHARP 입력 fx/fy/cx/cy 직접 사용 |
| 메시 | job_000002, 아래가 열린 형상 | 새 사진의 job_000003 + 별도 하단 캡 |
| 접지 | 월드 AABB 최저 Y | 법선 방향 하위 2% 정점, 15mm 매립 |
| 그림자 | 원형 방사형 텍스처 | 하단 투영 윤곽, 접촉 0.58 + 앰비언트 0.22 |
| 톤 | 기존 재질 그대로 | 현장 상자 영역 평균 기반 노출·채도·RGB 비율 조절 |
| 구조물 표시 | ID 라벨 및 추정 크기 | ID 기본 숨김, 대장 크기 `—` |

그림자 색은 주변 바닥 평균을 어둡게 한 RGB `[37,34,32]`입니다. 넓은 층을 약 2–3cm 편향시켜 사진의 그림자 방향과 대략 맞췄습니다. 정밀 광원 추정은 아닙니다. 조명의 위쪽과 방향도 바닥 법선에 맞췄습니다. 텍스처는 최대 768px 및 0.45px 블러를 사용하고 하단은 약하게 어둡게 처리합니다.

원본 및 ±5° 모두 EQ-0008 등록, 간섭 0건·0.50m 이격 기준 통과, 15mm 매립, 구조물 ID 라벨 0개, 카메라 fx/fy 투영 일치, 브라우저 오류 0건을 자동 확인했습니다. 기존 네 장면의 배치·정착·비간섭 회귀도 통과했습니다(`../gravity-regression-browser.json`). 최종 높이는 모두 0.35m입니다. 위 비교는 동일한 원본 카메라와 추천 위치를 사용하며, 수정 후 지지점을 피팅한 바닥면으로 투영했습니다. 메시와 yaw는 교체 전후에 다릅니다.
