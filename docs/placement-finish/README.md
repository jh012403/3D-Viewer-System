# 상자 배치 마무리

[원본·좌우 최대 각도 비교](index.html). 수정 전은 승인된 94bc18b의 동일 job_000003, 높이 0.35m, 동일 지지점·yaw입니다. 이전 캡처·시연 자산은 보존했습니다.

- 현장 사진의 같은 팔레트 상자에서 윗면과 오른쪽 옆면 다각형을 지정해 평균 RGB 휘도를 구했습니다. 목표 밝기 비율은 1.88375입니다. 이 비율은 선택한 사진 영역의 표시 RGB 값이며 물리적 반사율이나 실측 조도는 아닙니다.
- 중력 법선과 메시 월드 법선의 내적으로 위쪽 방향광 응답을 추가했습니다. 윗면의 선형 광량 배율은 1.20011, 옆면은 기존 음영을 유지합니다. 실제 출력 샘플의 윗면/옆면 비율은 1.88377입니다(`face-brightness.json`). 텍스처·접지·정규화는 유지합니다.
- 바닥 투영 윤곽에 폭 0.012m, 불투명도 0.92의 어두운 모서리 그림자를 추가했습니다. 기존 넓고 옅은 그림자와 좁은 접촉 그림자도 유지합니다. 사진 속 발밑 그림자를 육안 기준으로 참고했으며 자동 광원 추정 결과는 아닙니다.
- 수평 orbit은 ±3°로 제한했습니다. 회전 방향 가장자리에는 최대 6.5% 알파 페이드를 적용하며, 원본 시점에서는 페이드가 없습니다. 카메라 intrinsics는 바꾸지 않습니다. 원본 PNG 저장도 원본 투영을 유지합니다.

`after.json`은 실제 ±3° 도달, EQ-0008 등록, 간섭 없음·0.50m 이격 기준, 15mm 접지 및 구조물 ID 숨김을 기록합니다. 브라우저 오류 0건, 프로덕션 빌드 통과. 비교 PNG 세 장은 1920×1080입니다.
